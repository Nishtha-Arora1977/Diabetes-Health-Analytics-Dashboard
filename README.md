# 🩺 Diabetes Health Analytics Dashboard

An interactive Tableau dashboard designed to analyze diabetes-related health metrics and patient insights using data visualization techniques.

---

## 📊 Dashboard Features

- Diabetes vs Non-Diabetes Distribution
- BMI Analysis by Age Group
- Blood Pressure Visualization
- Health Metrics Heatmap
- Glucose & Insulin Analysis
- Age-wise Health Insights
- Interactive Healthcare Dashboard

---

## 🛠 Tools & Technologies Used

- Tableau
- Data Visualization
- Healthcare Analytics
- CSV Dataset
- Dashboard Design

---

## 📈 Key Insights

- Majority of patients are non-diabetic in the dataset.
- BMI and blood pressure vary significantly across age groups.
- Certain age groups show higher glucose and insulin levels.
- Heatmap visualization helps identify patterns in health indicators.
- Age group 45–60 shows increased diabetes-related health risks.
